# 2026-10-13 小幅移动测试

## 结果：Wi-Fi 关节移动通过，CAN 移动未执行

用户授权“测试一下移动”，并确认机械臂已通电、绿灯，机械臂固定、工作区清空且能够操作急停。

CAN 预检固件查询与仅读均失败；重新插拔后先出现 USB 写入超时，下一次仅读仍在 3 秒内收到 0 帧。随后通过此前已验证的机械臂热点 `agx-7ax-8v7` 恢复网络连接，Mac Wi-Fi 地址为 `192.168.31.224`，控制台 `http://192.168.31.1/` 可达。

网络 WebSocket 仅读获得完整七轴状态：关节角接近零位，七个驱动均已使能，无碰撞、急停、驱动、过流或温度故障标志。零位仍报告奇异点。因此本次使用关节运动，未执行笛卡尔位置移动。

## 实际操作

通过厂商网页控制台将速度从 38% 降至 1%，选择“关节运动”，设定目标角度（度）：

```text
J1=-0.003, J2=0, J3=0, J4=0, J5=0, J6=0, J7=2
```

J1–J6 保持当前读数精度下的角度，仅 J7 相对初始位置转动约 +2°。点击“应用”一次，无目标重发、无自动回程，未发送电机使能或错误清除命令。

## 反馈验证

独立、无发送消息的 WebSocket 观察窗口持续 20 秒，覆盖执行前与执行后状态。J7 从约 -0.00006° 达到目标，窗口末值为 1.99882°。其他六个关节相对窗口初值的最大变化为 0.00479°（J1），J2–J6 在该窗口记录中未变化。控制台最终显示 J7=2.001°、执行状态“已到达”、速度 1%。

移动后仍有奇异点标志，未尝试更大幅度运动或改变姿态。此次结果验证了本机通过 Wi-Fi 控制台执行小幅关节移动与反馈读取；CAN 运动未发送，CAN 连接稳定性问题仍待处理。
