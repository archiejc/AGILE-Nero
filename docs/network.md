# NERO Wi-Fi / 以太网接入

NERO 支持 CAN、HTTP、TCP，并提供 Wi-Fi 天线与以太网接口。网络接入可避开 Mac 上的 USB-CAN 传输链路。

## Wi-Fi 网页控制台

厂商 NERO 用户手册 V1.0.0 第 4.1 节记录以下默认值：

| 项目 | 默认值 |
| --- | --- |
| Wi-Fi 热点 | `agx-7ax-xx`（后缀以实际设备为准） |
| Wi-Fi 密码 | `12345678` |
| 网页地址 | `http://192.168.31.1/` |
| 网页账号 | `admin` |
| 网页密码 | `123456` |

这些是公开的出厂默认值。若设备网络或账号已配置过，使用其实际值。

Mac 连接机械臂热点后，通过浏览器进入网页控制台。手册第 5.1.2 节说明该页面能显示各关节电机状态；顶部功能区另提供使能按钮。本阶段先检查实时状态，不提交关节角、末端位置或轨迹。

## 以太网

第 4.2 节记录默认控制器地址 `10.90.0.150`，电脑应处于相同网段。建议为机械臂使用独立网卡/网络接口；为该接口配置同网段地址时，应保留已有的上网网络配置，避免改动校园网接口。具体接口和地址在实际连接后核对。

长时间实验可优先评估有线以太网；Wi-Fi 适合先进入控制台核对状态。程序控制的可用协议、接口与连续轨迹能力均需在这台 1.11 固件设备上验证。

## Python 接口边界

已安装的官方 `pyAgxArm` 提供 `comm="can"`，其配置工厂当前仅建立 CAN 通信层。因此，不能直接用 IP 地址替换 `channel` 来启用 Wi-Fi。网页或网络 TCP/HTTP 的状态读取需单独核对控制器接口，后续再封装网络适配器。

2026-10-13 的[小幅移动记录](motion-test-2026-10-13.md)记载了通过 Wi-Fi 控制台读取状态和执行一次 J7 小幅运动。该历史结果覆盖当次网页控制台操作；项目的程序化网络适配与连续绘画能力仍待实现和验收。使用前需要重新核对实时连接和设备状态。
