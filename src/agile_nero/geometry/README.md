# 统一几何与笔画 · geometry

**当前状态：规划；已有 DrawingTask 契约在 contracts。**

## 职责与边界

处理尺度、坐标、曲线转换与几何清理，把两条输入路线汇合为统一笔画。

## 输入与输出

图片候选线条或 CAD 曲线 + 用户尺度 → 毫米单位的 DrawingTask。
