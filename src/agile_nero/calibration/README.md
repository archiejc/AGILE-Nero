# 标定与坐标变换

**状态：设计中；本目录仅包含职责与验收说明，运行时尚未实现。**

## 边界

机器人线共享基础；geometry 管理内容尺度，本模块管理画板/基座/法兰/笔尖变换。

## 输入与输出

- 输入：RobotModelManifest、测量与工具/画板安装条件。
- 输出：CalibrationBundle：变换、测量残差、版本及适用条件。

## 验收目标

对应关口：R1。合成变换往返与已知姿态一致；真实标定须另有测量记录。先建立 synthetic 样例，不提供猜测的实机参数。
