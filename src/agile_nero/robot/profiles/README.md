# 设备能力与固件描述

**状态：设计中；本目录仅包含职责与验收说明，运行时尚未实现。**

## 边界

机器人线共享基础；声明支持哪些程序语义，不承担设备运动。

## 输入与输出

- 输入：确认的型号、固件及来源、SDK/后端版本。
- 输出：RobotProfile：版本化能力表；未知能力标为 unsupported。
