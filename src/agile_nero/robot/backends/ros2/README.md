# ROS2 / MoveIt2 后端

**状态：设计中；本目录仅包含职责与验收说明，运行时尚未实现。**

## 边界

规划、ROS 通信和设备驱动分别管理；本目录不代表 ROS 环境已经部署。

## 输入与输出

- 输入：经规划的轨迹、RobotProfile、模型与控制接口约定。
- 输出：带时间的关节轨迹及 FollowJointTrajectory 请求描述。

## 验收目标

对应关口：R2 / R3。离线检查关节顺序、rad / s、时间单调性、反馈和取消语义；后续再验收实际驱动与笔尖跟踪。
