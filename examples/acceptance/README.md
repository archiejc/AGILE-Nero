# 双线共用验收样例

基准编号：line-arc-lift-v1。它是合成的离线几何样例，未关联任何真实机械臂位置或标定。

工作区 100 × 80 mm，原点在画板左下角，x 向右、y 向上、z 离开画板。绘制面 z=0，抬笔面 z=5 mm，最大绘制采样间距 2 mm。

| 笔画 | 解析几何 |
| --- | --- |
| line-a | (10,10) → (40,10)，长 30 mm |
| line-b | (40,20) → (40,50)，长 30 mm |
| arc-c | 圆心 (70,40)，半径 10 mm；从 (60,40) 经 (70,50) 到 (80,40) 的上半圆，方向从 180° 递减到 0° |

[acceptance-pattern.json](../drawing/acceptance-pattern.json) 使用已有 DrawingTask 格式，将圆弧采为 16 条弦，保留三个独立笔画。它供现有离线程序验收；未来 CAD/SVG 导入器还应保留原生圆弧来源，不能把这份折线样例误当作控制器原生圆弧程序。

## 内容线完成标准

- 两条直线端点和长度与解析定义一致；圆弧端点及方向正确。
- 对这个合成样例，最大弦偏差不超过 0.1 mm。此数值是离散几何验收阈值，不是机械臂精度承诺。
- 恰好三个独立笔画，各有落笔和抬笔；两次笔画间移动保持在抬笔面。
- 现有规划器应得到 55 个路径点，折线绘制总长约 91.365485 mm，几何检查通过。
- JSON / SVG / 报告引用同一版本的输入与路径；支持的输入不可静默丢失实体。

## 机器人线完成标准

先用明确标为 synthetic 的模型配置/标定验证坐标变换，再定义一个后端的编译和验证流程。准备产物必须包含模型、TCP、画板、能力版本及起始状态条件，并区分接近、绘制、抬笔空行程和撤离。

尚未确定、尚未实施的部分：实际工具尺寸、画板位姿、初始关节状态、速度/加速度与停止策略、真实误差和接触阈值。它们需要后续模型/标定工作和独立授权的实机验收。样例本身不携带执行授权。

## 离线运行

从仓库根目录运行，输出目录使用新名称：

```sh
PYTHONPATH=src python3.12 -S -m agile_nero.api --input examples/drawing/acceptance-pattern.json --output-dir outputs/acceptance-v1
```
